## amazon-clone-html-css

A fully responsive Amazon homepage clone built using HTML and CSS. This project focuses on layout structuring, responsive design using Flexbox and adds interactivity using transitions and transform effects.

## Features

- semantic HTML structure
- Fully styled with css
- Custom navbar and footer
- Product Section mockup
- Hover effects for interactivity
